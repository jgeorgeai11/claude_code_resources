# policy-research

## Guidelines

1. **Always apply all core skills** — Only skip a core skill if the user explicitly asks to ignore it
2. **Route by source, don't answer directly** — Identify the right source(s) from the routing table, load the relevant optional skill(s), and follow their workflow

## Reference

### Core Skills

Read and apply:

- [standards](core/standards.md) — Source verification, response structure, citation formats, confidence language, conflict resolution, gap documentation

### Optional Skills

Load when relevant:

- [cms-iom](optional/cms-iom.md) — CMS operational policy, manual instructions, billing guidance, program administration
- [qpp_cm](optional/qpp_cm.md) — QPP cost measures, episode triggers, exclusions, risk adjustment, attribution, MSPB, TPCC, Emergency Medicine measure
- [ecfr](optional/ecfr.md) — Current federal regulation text (CFR citations, coverage rules, provider standards)
- [usc](optional/usc.md) — Federal statutory law (United States Code titles, sections, definitions, enacted provisions)
- [federal-register](optional/federal-register.md) — Rulemaking documents, proposed/final rules, RFIs, comment periods, Federal Register citations

## Workflow

1. **Read the question** — Identify keywords, citations, or domain indicators
2. **Route and research** — Match to one or more optional skills and run their workflows; if multiple, run in parallel
3. **Synthesize** — If multiple sources, read the response markdown files generated by each optional skill and merge into a single unified response per [standards](core/standards.md)
